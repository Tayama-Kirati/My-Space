# My Personal Digital Space

A personal content management site built for daily use — journal writing, book logging, focus sessions, and a photo memory gallery. Built by **Tayama Kirati**, based in Nepal.

---

 
## Features

### Journal

- Click any past date to write or edit an entry
- Upload a custom cover photo for each month  
- Year overview: 12 mini month cards at a glance
- Entries saved locally — no account needed

### Memories
- Add pictures with captions.
- Shows the timeline of the pictures added .


### Books
- Personal reading list — **sorted highest star rating first**
- Featured book section highlights the top pick
- Each book card shows title, author, my personal review, and a star badge on the cover
- **"Write About a Book" modal** — log any book you have finished with a description, review, rating, and date
- Stats bar in the hero: total books read, average rating, five-star count

### Memories
- Masonry photo gallery with drag-and-drop or file upload
- Add caption, location, mood emoji, and date to each photo
- Lightbox view on click (press Escape to close)
- Timeline sidebar grouped by month with jump-to links
- Delete any memory with one click

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app runs at `http://localhost:5173` by default.
